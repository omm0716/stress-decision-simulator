# 🛡️ 의사결정 스트레스 테스터 (Stress Decision Simulator)

> **"행복회로를 끄고, 최악의 폭락장과 멘탈 마지노선을 직면하는 현실적 의사결정 시뮬레이터"**

기존 복리 계산기는 "매달 100만 원씩 10년 모으면 1.8억 원!"이라는 장밋빛 숫자만 보여줍니다.  
하지만 현실에서는 **3~4년 차에 폭락장을 만나 잔고가 -30% 꺾이는 순간 공황 상태로 바닥에서 손절**하게 됩니다.

본 프로젝트는 **'최악의 순간(하락장과 생활비 누수)을 미리 마주하게 하여 끝까지 살아남는 현실적 투자 계획'**을 세울 수 있도록 돕는 클라이언트 사이드 웹 애플리케이션입니다.

---

## ✨ 핵심 차별화 기능 (Key Features)

1. **💸 현실 라이프스타일 누수 변수 (Life Friction)**
   - 배달음식 / 외식 충동 횟수 및 **방어율(참아낸 비율 %)** 슬라이더
   - 명절, 경조사, 병원비 등 **연간 돌발 이벤트 빈도** 반영
2. **⚡ 시장 폭락 스트레스 모드 (Crash Scenarios)**
   - **온실 속 화초**: 급락 없는 평온한 장밋빛 복리 상승
   - **현실적 조정**: 중간 1회 -28% 급락장 충격
   - **블랙스완 대공황**: 2008년 금융위기급 연쇄 폭락 (-35% & -45%)으로 멘탈 극한 시험
3. **📊 3중 자산 궤적 비교 시각화 (Recharts)**
   - 🌟 장밋빛 이상적 복리 (누수 0) vs 💼 현실 지출 반영 잔고 vs ⚠️ 폭락장 스트레스 잔고
4. **❤️ 멘탈 마지노선 진단서 & 행동 처방전**
   - 멘탈 붕괴 위험 지수(0~100점) 및 4단계 등급 (`강철 멘탈` / `심장 쫄깃` / `패닉 경계` / `붕괴 위험`)
   - 최대 고통 낙폭(MDD, %)과 최악의 고비 연차 진단
   - 즉시 실천 가능한 1줄 행동 처방전 제공 & 원클릭 결과 복사
5. **🍕 기회비용 현실 체감 환산기**
   - 배달 및 누수 지출이 복리로 날아간 총 미래 가치 산출
   - "매년 최신 플래그십 스마트폰 N대 / 해외여행 N회 분량" 직관적 체감 제공

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS v4
- **Visualization:** Recharts
- **Icons:** Lucide React
- **Architecture:** Pure Client-side SPA (No Backend/Server Required, Zero Maintenance)

---

## 🚀 로컬 실행 방법 (Getting Started)

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 브라우저 접속
# http://localhost:5173
```
